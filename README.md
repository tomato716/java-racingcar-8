# java-racingcar-precourse

## 구현 기능 목록

- [x] `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`를 출력한다.
- [x] 경주할 자동차 이름을 입력받는다.
  - [x] 이름은 5자 이하만 가능
  - [x] 이름은 1자 이상만 가능
  - [x] 이름은 (,)쉼표로 구분
  - [x] 자동차 이름에 공백은 미포함
  - [ ] 중복된 이름은 불가능
  - [x] 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException` 예외 발생
- [x] `시도할 횟수는 몇 회인가요?`를 출력한다.
- [x] 시도할 라운드 횟수를 입력받는다.
  - [x] 시도 횟수가 숫자가 아니라면 `IllegalArgumentException` 예외 발생
- [x] `실행 결과`를 출력한다.
  - [x] 각 자동차가 0~9 사이 랜덤 숫자를 뽑아, 4 이상일 경우 전진
  - [x] 라운드 별 진행 상황을 출력한다.
- [x] 최종 우승자를 출력한다.
  - [x] 우승자가 여러 명일 경우 (,)를 이용해 구분
